# 🐉 Easy Yu-Gi-Oh! Legacy Tool

> A simple fan-made tool that helps new players create a **Dragon Starter Pack** and quickly begin exploring powerful Dragon Fusion combinations in **Yu-Gi-Oh! Legacy**.

## 🐉 Dragon Starter Pack

Starting a new game can take time. Players often need to collect many cards before they can begin experimenting with powerful Fusion combinations.

**Easy Yu-Gi-Oh! Legacy Tool** provides a convenient way to create a **Dragon Starter Pack** containing key cards for a Dragon-focused playthrough.

The goal is simple:

> Give new players a useful collection of Dragon, Thunder, and support cards so they can start playing and experimenting with Fusion immediately.

## ⚡ Thunder + Dragon Strategy

The pack includes several Dragon and Thunder monsters that can be used as Fusion materials.

The basic idea is to build toward the required combination:

```text
🐉 Dragon
   ↓
⚡ Thunder
   ↓
🐉 Dragon
   ↓
⚡ Thunder
   ↓
🐲 Dragon Titan
```

Players can experiment with different ways of getting the required monsters onto the field and discover Fusion combinations naturally through gameplay.

## 💪 ATK Requirement

One important part of the Dragon Titan Fusion is the Thunder monster's ATK requirement.

The relevant Thunder Fusion material must have:

```text
ATK > 1000
```

This means that not every Thunder monster will work for the combination.

The Dragon Starter Pack includes multiple Thunder monsters so players have more opportunities to experiment with Fusion combinations and understand how the Legacy Fusion system works.

## 🎮 Designed for New Players

The purpose of this tool is **not** to create a fully optimized competitive deck.

Instead, it provides a useful starting point.

A new player can:

1. 🐉 Create the Dragon Starter Pack
2. 🎴 Add the cards to their game
3. 🎮 Start playing
4. 🧬 Experiment with Fusion combinations
5. ⚡ Combine Dragon and Thunder monsters
6. 🐲 Work toward Dragon Titan
7. 🃏 Continue collecting cards and improving their deck

This makes the early game more accessible while still allowing players to discover and learn the Fusion system themselves.

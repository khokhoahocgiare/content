The tool is designed to detect the running **Yu-Gi-Oh! Forbidden Legacy** game process and apply a Life Point modification to the player during supported duels.

              ▼

 Set player LP → 999,999,999

> **Important:** Make sure the game is already running before launching or using the tool.

## 📥 Installation and usage

1. Download the latest release from the **GitHub Releases** page.
2. Extract the downloaded file if it is provided as an archive.
3. Launch **Yu-Gi-Oh! Forbidden Legacy**.
4. Enter a supported duel mode.
5. Open the **999,999,999 Life Points Tool**.
6. Wait for the tool to detect the running game process.
7. Apply the Life Point boost.
8. Continue the duel with your Life Points increased to **999,999,999 LP**.

If the tool cannot detect the game process, check the following:

- The game is currently running.
- You have entered a duel before applying the modification.
- You are using a supported version of the game.
- The game executable has not been renamed or changed.
- The tool has sufficient permission to access the game process.
- You are running both the game and the tool at the same permission level.
